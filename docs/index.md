# Dark Horse Digital — Engineering Knowledge Base

Welcome. This is the central, version-controlled home for engineering documentation at
Dark Horse Digital Solutions Pvt Ltd: architecture decisions, runbooks, coding standards,
and onboarding material.

## Why a Git-based KB

Everything here lives in a Git repository as plain Markdown, rendered into this site.
That means:

- **Pull requests for documentation.** Changes to process or architecture go through the
  same review workflow as code.
- **Full history.** `git log` and `git blame` tell you who changed what, and when — no
  more guessing which wiki edit is current.
- **No platform lock-in.** Markdown files are portable; this is not tied to any single
  wiki vendor.
- **Docs live next to the people who write code.** Anyone with repo access can propose a
  change with a familiar tool.
