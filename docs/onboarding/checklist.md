# New Joiner Checklist

## Day 1

- [ ] GitHub organization access granted
- [ ] Added to relevant team repositories
- [ ] Slack / email / calendar access confirmed
- [ ] Read [Getting Started](../getting-started/index.md)
- [ ] Local dev environment set up — see [Local dev setup](../getting-started/local-setup.md)
- [ ] Introduced to your onboarding buddy / manager

## Week 1

- [ ] Read [Coding standards](../coding-standards/index.md)
- [ ] Read [Architecture overview](../architecture/index.md)
- [ ] Skim [Runbooks](../runbooks/index.md) so you know they exist before you need them
- [ ] Make a first small pull request (docs fix counts!)
- [ ] Understand your team's PR review and deployment process

## First month

- [ ] Understand how this knowledge base works and how to contribute to it —
      see [CONTRIBUTING.md](https://github.com/<your-github-org>/<your-repo-name>/blob/main/CONTRIBUTING.md)
- [ ] Shadow an on-call rotation or incident, if applicable
- [ ] Identify one piece of undocumented tribal knowledge and write it down here

## Notes for the person maintaining this checklist

Update this file whenever onboarding steps change — it should reflect reality, not the
process as it existed when this was first written.
